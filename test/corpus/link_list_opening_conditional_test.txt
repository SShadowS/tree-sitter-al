; G11 (deferred-work item 18): a #if that OPENS a link list continued after
; #endif is list-internal: link_value_list(preproc_conditional_link_values ...),
; one property. alc accepts every form here with X defined and undefined.
; Since G8 the unquoted form was a SILENT misparse -- a terminator-less property
; whose value was preproc_conditional_property_value, then a second property
; named `B` -- and the quoted form ERRORed. Two causes: link_value_list's
; prec.left(6) beat the list-internal _link_value_branch statically, and the
; `;`-inside-the-arms whole value let an arm end with no `;`.
; The last four cases are whole-value forms that must stay
; preproc_conditional_property_value. Expected trees from `tree-sitter parse`.
