NEGATIVE: #regionX is not a directive -- alc rejects it with AL0621
Until 4.0.0 preproc_region matched the keyword with no trailing word boundary,
so any identifier beginning "region" lexed as a whole region directive. This
case previously asserted the OPPOSITE: that #regionX parsed cleanly between a
split end; and its #else. That was the scanner being aligned to an
over-permissive grammar in 3bcd3d1; the grammar has now moved instead.
tree-sitter's lexer compiler rejects zero-width assertions, so neither a
word-boundary escape nor lookahead is available; the boundary is expressed as a
MANDATORY non-word character absorbed by the existing trailing wildcard. One
consequence is visible below -- #region still matches as a seven-character
prefix and the tail is left over, rather than the directive failing to match
outright. The file is rejected either way, which is what alc does too.
================================================================================
codeunit 1 T
{
    procedure X()
    var
        x: Integer;
    begin
        if x = 1 then begin
            x := 9;
#if not CLEAN22
        end;
#regionX Foo
#else
        x := 2;
        end else begin x := 3; end;
#endif
    end;
}

================================================================================
`#elifX` is not `#elif` -- a directive keyword needs a word boundary
--
DELIBERATE NEGATIVE: the ERROR is the assertion. This file is already exempt in
validate-grammar.sh Step 3 and release.md pre-flight #3.
.
alc 18.0.37.11445 REJECTS `#elifX OTHER` with AL0621 "Preprocessor directive
expected", and ACCEPTS `#elif OTHER` in the identical file. Same rule the
existing cases here pin for `#regionX` and `#pragmaX`.
.
This case previously lived in scanner_single_read_dispatch_test.txt asserting
the OPPOSITE -- that `#elifX` parses as a clean `#elif` with a condition. That
made it the sixth shipped fixture blessing a defect. It surfaced only because
bounding the directive condition to its line made the malformed directive fail
to parse; the fixture had been green while asserting something alc refuses.
================================================================================

codeunit 1 T
{
    procedure X()
    var
        x: Integer;
    begin
        if x = 1 then begin
            x := 9;
#if not CLEAN22
        end;
#elifX OTHER
        x := 2;
        end else begin x := 3; end;
#endif
    end;
