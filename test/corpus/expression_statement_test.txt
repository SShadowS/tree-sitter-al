; B6 positives: statement shapes alc accepts (or could reject only with symbols), and the
; operator words where alc accepts them: declared as names (enum value, field, option member,
; procedure) and quoted in code (`"and"(C);`); `is` and `as` stay bare names in code. Spec
; docs/superpowers/specs/2026-10-06-expression-statement-narrowing-design.md §5.2; alc evidence
; tools/alc_probe/cases/expression-statement/accept-*.al.
;
; Current behaviour, not a contract: `Bar;` gives a `call_statement`, while `Bar` before `end`
; and `Order;` give a bare `identifier`. That two-shape split predates B6 and is pinned here
; only so a change to it is seen.
