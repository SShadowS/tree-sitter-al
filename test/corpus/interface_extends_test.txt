================================================================================
Interface extends, with the access modifier where AL actually puts it
--
`interface X extends Y access = Internal { }` was accepted here until 4.0.0.
alc rejects it (AL0104, "',' expected" -- it reads `access` as a second
interface in the extends list), and the field it populated was never once
populated across BC.History. Access is a BODY property; extends is the only
thing that follows the object name.
================================================================================

interface "My Interface" extends MyBaseInterface
{
    Access = Internal;
    procedure DoSomething();
}
