; A #if that follows a global var section and holds procedures is a SIBLING
; of the var section, never part of it. Until this fixture var_body admitted
; preproc_split_procedure and preproc_conditional_var admitted any body
; element, so 459 procedures in 84 files (BC.History, BC 28.1, DC) were
; parsed inside var_section; every single-configuration parse disagreed.
; Found by the configuration-consistency oracle (docs/deferred-work.md item 8).
; Case 2 is the one real crossing: the branch continues the var section and
; then starts the procedures (alc accepts it flat and split, CLEAN25 set and
; unset); preproc_split_var_section_tail holds it.
