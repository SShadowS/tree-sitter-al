; B5b (spec 2026-10-05-link-keying-design.md): the six link-family names (ColumnFilter,
; DataItemLink, DataItemTableFilter, LinkFields, RunPageLink, SubPageLink) are keyed by the
; scanner, and only they reach link_value_list. A generic name with link-shaped text is a
; property_expression (L1). const() takes a decimal, a biginteger and a `-`-signed number as
; ONE value node (L3). The G11 variants, the mixed placement and the const forms are verbatim
; Task 1 probes, accepted by alc 18.0.41 in the recorded assignments
; (tools/alc_probe/cases/link-keying/README-verdicts.txt). No production DataItemLink carries
; a comment (searched BC.History, DC, BC28.1, BCApps-29.0), so the comment case is the probe.
; Expected trees from tools/snip.py --sexp, with field labels.
