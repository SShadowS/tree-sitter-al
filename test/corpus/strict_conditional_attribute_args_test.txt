; B7b-1 Task 10: #if groups in attribute argument lists `[Attr(a, b)]` (family attribute_args,
; grammar.js strictConditionalList). The list is everything between `(` and `)` of attribute_arguments;
; attribute_argument_list stays visible and unfielded, and attribute_arguments' `optional(...)` wrapper is
; unchanged, so `[A()]` still has no attribute_argument_list.
; The first 10 cases are the shapes of b7_gap_attribute_arguments_test.txt that now parse, argument text
; unchanged. `MIXED` cases are accepted by alc in one configuration and rejected (semantically: argument
; count / AL0238 class) in the other: the split source parses, the invalid configuration is the config
; oracle's to judge (spec section 3). An emptied configuration flat-parses as `[A()]` (optional
; wrapper, spec 4.2 case 2): the oracle lowers it with optional-list-removed:attribute_argument_list.
; Trees are hand-written from the flat reading, never copied from parser output.
