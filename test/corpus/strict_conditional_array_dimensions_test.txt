; B7b-1 Task 9: #if groups in the dimension list of array[...] of T (family array_dimensions,
; grammar.js strictConditionalList). The list is everything between `[` and `]`; each dimension stays
; `sizes:` (on the group node when it sits inside an arm).
; The first 19 cases are the shapes of b7_gap_array_dimensions_test.txt that now parse, dimension text
; unchanged. `MIXED` cases are accepted by alc in one configuration and rejected in the other (AL0367
; empty dimension list, AL0301/AL0107 separators): the split source parses, the invalid configuration
; is the config oracle's to judge (spec section 3).
; An emptied dimension list stays a flat-grammar error: alc rejects it (AL0367, B7b-1 Task 2,
; empty-semantic-rejected), so `sizes` is never optional in the flat reading.
; Trees are hand-written from the flat reading, never copied from parser output.
