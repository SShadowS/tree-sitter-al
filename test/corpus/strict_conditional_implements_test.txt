; B7b-1 (spec docs/superpowers/specs/2026-10-07-b7b-1-strict-conditional-lists-design.md):
; a #if group may stand anywhere in implements_clause's interface list. Expected trees are
; HAND-WRITTEN from the flat reading (the item list with each arm read as an alternative item
; run): every raw interface is fielded `interface`, on implements_clause when it sits outside a
; group and on preproc_conditional_implements when it sits in an arm. Separators are anonymous.
; Comments sit in the smallest visible node holding tokens on both sides of them.
; The `MIXED` cases are the B7a witnesses alc accepts in one configuration and rejects in the
; other (manifest tools/b7_audit/b7b1-manifest.tsv): the split source parses, the invalid
; configuration is the config oracle's to judge (spec section 3). They replace the `:error`
; cases of the former test/corpus/b7_gap_implements_test.txt, whose shapes all live here now.
