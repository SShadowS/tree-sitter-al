; B7b-1 Task 12: #if groups in the name list of an ATTRIBUTED variable declaration. The `[` of a variable
; attribute is the external token var_attribute_open, decided by a scanner lookahead from the `[` to the
; declaration's `:` (src/scanner.c var_name_list_follows). Each case pins which node owns the `[`:
; var_attribute_item for a declaration, attribute_item for a procedure. The shapes are the ones alc accepts
; syntactically (B7b-1 Task 2, probes tools/alc_probe/cases/b7b1/vn__* and pa__*); `MIXED` cases are
; accepted by alc in one configuration and rejected (AL0104/AL0107, syntax of the selected text) in the
; other. The procedure counterparts keep the trees they had before Task 12.
; Trees are hand-written from the flat reading, never copied from parser output.
