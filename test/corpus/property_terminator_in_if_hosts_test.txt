; G11 (deferred-work item 17): a property whose `;` sits inside the #if arms
; (`ToolTip = #if X 'a'; #else 'b'; #endif`, nothing after #endif) is a
; `property` at every host that lists properties. It was accepted only through
; _body_element, and ERRORed at the two hosts that list `$.property` directly:
; an action area (_action_element) and assembly_body. alc accepts all three
; cases in all four configurations. The group case always parsed (an action
; group's body also takes _body_element) and is pinned unchanged. Expected trees from
; `tree-sitter parse`.

================================================================================

    actions

        area(Embedding)
        {
            ToolTip =
#if X
                    'a';
#else
                    'b';
#endif
            action(A) { RunObject = page P; }
