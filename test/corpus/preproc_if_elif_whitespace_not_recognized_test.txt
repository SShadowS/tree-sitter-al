================================================================================
DOCUMENTED NON-SUPPORT: `# if` with a single horizontal space is NOT
recognized as `preproc_if` — no literal-variant route was added (unlike
`# pragma`/`# region`/`# endregion`, which ARE tolerant; see
pragma_whitespace_tolerance_test.txt and preproc_region_whitespace_audit_test.txt).
A spaced `# if`/`# elif` was tried as a preventive literal-variant fix
(mirroring the pre-existing `# else`/`# endif` variants) but reverted after
review found it introduced genuine GLR non-determinism in the pre-existing
`preproc_split_if_then_begin_else_shared` construct (two mutually-exclusive
stable parses across process states for byte-identical input) plus a silent
shape defect under `#if`-nesting (the literal-variant token does not
participate in the external scanner's depth counter, so a nested spaced
`# if` undercounts depth and the enclosing code_block loses its begin/end
keyword naming). No corpus instance of a spaced `# if`/`# elif` has ever been
found (the feature was purely preventive); dropping it costs nothing real.
The engine's `ParseStatus::Recovered` diagnostic is the intended detection
path if a real instance ever surfaces — a file using `# if`/`# elif` recovers
(as shown below) rather than parsing clean, so it is flagged for triage
rather than silently producing a wrong (or non-deterministic) tree. A future
fix, if warranted by a real corpus hit, belongs in the external scanner
(so it participates in the depth counter), not as another literal variant.
================================================================================

codeunit 50000 "If Test"
{
    # if CLEAN24
    procedure Test()
    begin
    end;
    # endif
}

================================================================================
NEGATIVE: `#` then a bare LF then `if` on the next line must NOT be recognized
as `#if` — horizontal-only tolerance, never a cross-line match. The CRLF
variant (`#\r\nif`) shares this exact proof and was verified empirically via a
standalone (uncommitted) `tree-sitter parse` scratch fixture rather than here,
for the same `.gitattributes` `eol=lf` normalization reason documented in
pragma_whitespace_tolerance_test.txt — a committed CRLF fixture would silently
become this LF one on checkout, which is not honest coverage
================================================================================
