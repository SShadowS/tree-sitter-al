================================================================================
Issue #34: an extension may name its base object by number
--
`tableextension 50102 "X" extends 50101` used to make the whole object a root
ERROR: base_object took only a name. alc 18.0.41 accepts a number for the
table, page, report and enum extensions (tools/alc_probe/cases/issue34/), and
rejects it for a permissionset extension (AL0653,
extends_by_number_negative_test.txt). The assertion is `base_object: (integer)`.
================================================================================
