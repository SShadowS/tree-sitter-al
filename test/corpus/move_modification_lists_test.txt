; move* in a page extension takes a LIST of controls after the target, and is
; also legal inside actions. Neither shape occurred in BC.History/DC/BC 28.x;
; both occur in BC 29 (BCApps releases/29.0): moveafter("Address 2"; City,
; CountyGroup) in the GB postcode apps, CZ and FR localizations, and
; movebefore(Submit_Promoted; Generate_Promoted) in a CZ actions section.
; alc accepts both at runtime 15.0. See docs/bc29-parse-gaps.md families A, B.

========================================================================
move* with a list of controls
========================================================================
pageextension 50100 E extends P
{
    layout
    {
        moveafter("Address 2"; City, CountyGroup)
        movefirst(General; "No.", Name, "Search Name")
        movelast(General; Blocked)
        movebefore(Name; "Name 2", Address)
    }
}
