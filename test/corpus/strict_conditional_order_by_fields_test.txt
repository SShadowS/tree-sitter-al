; B7b-1 (spec docs/superpowers/specs/2026-10-07-b7b-1-strict-conditional-lists-design.md):
; a #if group may stand anywhere in the inner field list of one OrderBy item, inside
; ascending( ... ) or descending( ... ). The outer comma list of order_by_items is property-value
; routing and is NOT strict (excluded, spec section 2): a group between two items stays an ERROR,
; pinned in strict_conditional_order_by_fields_negative_test.txt. Expected trees are HAND-WRITTEN
; from the flat reading (the item list with each arm read as an alternative item run). The list is
; unfielded: its raw items are unfielded children of order_by_item, items inside an arm unfielded
; children of preproc_conditional_order_by_fields. Separators are anonymous. Comments sit in the
; smallest visible node holding tokens on both sides of them.
; The first 10 cases are the shapes of the former test/corpus/b7_gap_order_by_test.txt `:error`
; witnesses, list text unchanged (query OrderBy, the probed route). `MIXED` cases are accepted by
; alc in one configuration and rejected in the other: the split source parses, the invalid
; configuration is the config oracle's to judge (spec section 3).
; The interior may be empty: alc accepts `ascending()` (B7b-1 Task 2, empty-interior), so the
; configuration X=0 of the empty-list shape is a valid flat text.
