; value: table_relation_value(table_relation_expression

; `;` was an empty_statement sibling of the property, with no ERROR: the only
; rule that held `expression conditional` was _property_with_terminator_in_if,
; which takes no `;`. alc accepts all three in every configuration (split and
; flat). The third, an `else` before the #if, always parsed and is pinned
; unchanged.
; Expected trees from `tree-sitter parse`.
