; B7b-1 (spec docs/superpowers/specs/2026-10-07-b7b-1-strict-conditional-lists-design.md):
; a #if group may stand anywhere in the inner field list of sorting( ... ) in a view value
; (SourceTableView, RunPageView, DataItemTableView). Only the list inside the parentheses is
; strict: the order( ) and where( ) suffixes are untouched. Expected trees are HAND-WRITTEN from
; the flat reading (the item list with each arm read as an alternative item run). The list is
; unfielded: its raw items are unfielded children of sorting_value, items inside an arm unfielded
; children of preproc_conditional_sorting_fields. Separators are anonymous. Comments sit in the
; smallest visible node holding tokens on both sides of them.
; The first 19 cases are the shapes of the former test/corpus/b7_gap_sorting_test.txt `:error`
; witnesses, list text unchanged, on their probed route: an action's RunPageView whose whole value
; is a `#if TPL` group (tools/alc_probe/cases/b7-audit/sorting__*__{gap,overaccept}.al). The later cases use the
; property route (SourceTableView); alc accepts every route alike (tools/b7_audit/b7b1-manifest.tsv).
; `MIXED` cases are accepted by alc in some configurations and rejected in another: the split
; source parses, the invalid configuration is the config oracle's to judge (spec section 3).
; The interior may be empty: alc accepts `sorting()` on all six routes (B7b-1 Task 2,
; empty-interior), so the configuration X=0 of the empty-list shape is a valid flat text.
