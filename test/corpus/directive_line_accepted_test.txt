================================================================================
`//` comments after #if, #elif, #else and #endif are accepted
B2 (2026-10-01): alc accepts a trailing `//` comment on every conditional
directive (tools/config_oracle/probe_alc.py line_comment_on_if_else_endif,
elif_trailing_line_comment, else_line_comment_only). The trailing-content
check B2 added to #else/#endif must leave these clean, with the comment an
extra.
================================================================================
codeunit 50100 P
{
    trigger OnRun()
    begin
#if A // c
        Message('a');
#elif B // c
        Message('b');
#else // c
        Message('c');
#endif // c
    end;
}

================================================================================
#endregion; is accepted -- region lines take free text
alc accepts it (probe_alc.py endregion_semicolon_accepted), and it occurs in
production (the Continia connector, BC 28.1 and BCApps 29.0). B2's
trailing-content rule is for #else/#endif only.
================================================================================
codeunit 50100 P
{
    trigger OnRun()
    begin
#region R
        Message('a');
#endregion;
    end;
}
