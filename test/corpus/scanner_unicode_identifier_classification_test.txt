================================================================================
Astral-plane letter STARTING an identifier the scanner has to classify.
U+20000 is category Lo -- an ordinary CJK ideograph, and a plain letter to
grammar.js's `identifier: token(/[\p{L}_][\p{L}\p{N}_]*/u)`. The scanner decides
where PROPERTY_NAME starts before the generated lexer sees the text, so it needs
the same answer, and it used to ask iswalpha(). wint_t is 16 bits on Windows, so
the codepoint was TRUNCATED to U+0000, is_identifier_start said no, PROPERTY_NAME
declined, and this line came out as `(ERROR (identifier) (integer))` -- while the
ASCII `YProp` on the next line, in the identical position, parsed as a property.
wint_t is 32 bits on Linux, so the same bytes took a different path there: the
parser disagreed with ITSELF across platforms. Verified on Windows 11 /
mingw-w64 UCRT, sizeof(wint_t) == 2. The companion deliberate-negative lives in
scanner_unicode_identifier_negative_test.txt; it is separate so that THIS file
stays subject to validate-grammar.sh's ERROR/MISSING census.
.
Both properties below must be properties. The second is the control: if a future
change breaks identifiers wholesale rather than just the astral ones, this
fixture must not still pass.
================================================================================

table 50100 T
{
    𠀀Prop = 5;
    YProp = 5;
}

A \p{N} character continues an identifier, because grammar.js says so. U+00B2
SUPERSCRIPT TWO is category No. It is in `[\p{L}\p{N}_]*` and therefore in an
identifier, and it parsed as a property before this change too -- it is pinned to
fix the BOUNDARY, not to record a fix.
.
alc REJECTS this spelling (AL0107, verified at 18.0.37.11445), so grammar.js is
deliberately broader than the compiler here, per "parse structure, don't
validate". That gap is a grammar.js decision. If someone later narrows the
SCANNER toward alc without narrowing the grammar, they reintroduce exactly the
scanner-vs-grammar disagreement this change removed, and this fixture catches
it.
