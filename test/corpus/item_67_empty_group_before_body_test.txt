================================================================================
Item 67: an empty #if before a then-branch decorates it
--
The group used to BE the then_branch, with A() a sibling statement and `else`
a call named `else`, no ERROR. A directive-only group before a body slot is
now an unfielded preproc_conditional_statement before the fielded body. alc
accepts F=0 and F=1 (tools/alc_probe/cases/item67/then.al).
================================================================================
codeunit 1 C
{
    procedure P(R: Boolean; I: Integer)
    begin
        if R then
#if F
#endif
            A()
        else
            B();
    end;
}
--------------------------------------------------------------------------------
