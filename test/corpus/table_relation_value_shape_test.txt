; A table relation has ONE shape whether or not a #if follows it: every
; configuration of a multi-configuration value lowers to exactly the tree a
; flat parse of that configuration's text gives. Each conditional case below
; is paired with the flat text of one of its configurations.
;
; G1: when the property's `;` sits inside a #if arm (_property_with_terminator_in_if),
; the value used to have no table_relation_value wrapper, and the open if-chain
; form had no table_relation_expression either. Found by the configuration-
; consistency oracle (tools/config_oracle, milestone 2).
;
; G2: when the whole value is a #if, each arm used to be a
; table_relation_expression, which no flat parse gives: flat `Item;` is a
; generic `identifier` value, flat `"X";` a `quoted_identifier`, and only a
; longer relation is table_relation_value. Each arm now holds that value,
; whether the `;` sits inside the arms or after #endif.
;
; G6: a whole-value #if is preproc_conditional_property_value, each arm's value
; fielded `value`; it used to share preproc_conditional_table_relation with the
; genuine relation continuations, which keep that type.
